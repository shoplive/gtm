페이지 폭과 자리에 맞춰 형태를 정해요. 같은 숏폼 묶음을 다른 형태로 여러 곳에 놓을 수도 있어요.

격자형

숏폼을 바둑판처럼 펼쳐요. 아래로 스크롤하며 계속 보는 피드 페이지에 맞아요.

가로형

한 줄로 가로 스크롤해요. 메인이나 기획전 중간에 띠처럼 끼워 넣기 좋아요. 자동으로 흐르게 할 수도 있어요.

가로형 + 상품NEW

숏폼마다 연동된 상품이 바로 아래에 함께 보여요. 영상을 보고 바로 상품으로 갈 수 있어요.

주요 특징

모으기

조건만 정하면 알아서 모여요

  • 어드민에서 만든 숏폼 그룹을 그대로 전시
  • 태그·브랜드·카테고리 조건으로 자동 구성

  • 누르면 전체화면 플레이어로 이어서 시청

자동

상품과 연결된 숏폼만 골라서 떠요

  • 상품 번호(SKU)나 상품명으로 더 정확하게 연결
  • 연결된 숏폼이 없으면 나타나지 않아요
따라다님

스크롤해도 시야에 남아요

  • 상세 설명을 읽는 동안에도 계속 보여요
  • 네 모서리 중 원하는 위치에 두어요
  • 고객이 창 크기를 직접 조절하게 할 수도 있어요

닫으면 당분간 다시 뜨지 않아요

  • 닫은 뒤 다시 표시할 때까지의 시간을 정해요

  • 기존 페이지 구성은 건드리지 않아요

주요 특징

자유로운 자리

정해진 자리가 없어요

  • 상품 썸네일 자리를 통째로 숏폼으로
  • 상품 목록의 타일 하나하나에도
  • 상세 상단, 브랜드관 등 어디든 호출한 자리에 등장
간편한 적용

필요 시 맞춰 드릴 수 있어요

  • 원하는 자리에 호출 한 번이면 숏폼이 들어가요
  • 직접 수정이 어렵다면 샵라이브가 고객사용 스크립트로 위치·조건을 맞춰 드려요
  • 쇼핑몰 디자인이 바뀌어도 스크립트만 갱신하면 돼요
안정성

숏폼이 없으면 원래 화면 그대로예요

  • 숏폼을 불러온 뒤에만 자리를 바꿔요
  • 실패하면 기존 이미지를 건드리지 않아요
  • 숏폼마다 쇼케이스 노출을 켜고 끌 수 있어요

2쇼핑몰 · 샵라이브(필요 시)

놓을 자리를 정해요

썸네일 자리, 목록 타일 등 원하는 위치에 직접 호출해 넣어요. 직접 수정이 어렵다면 위치를 알려 주시면 샵라이브가 고객사용 스크립트에 담아 드릴 수 있어요.

이렇게 써보세요

CASE 01상품 상세
